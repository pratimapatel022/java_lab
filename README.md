This repository contains a collection of Java practice projects built to strengthen programming concepts such as OOP, File I/O, Collections, and GUI development.
Each project is designed to be simple, educational, and a step toward mastering Java.

**Technologies Used**
Java SE 17+

OOP Concepts (Encapsulation, Inheritance, Polymorphism)

Collections Framework (ArrayList, HashMap)

File I/O for persistenc


->**     How to Run**
Clone or download this repository.

Open in your IDE (IntelliJ, Eclipse, or VS Code).

Compile and run the desired project’s Main.java.

Follow on‑screen instructions to interact with the program.
